# 🌎 BioGuard

## O Que É?

Um app que monitora queimadas e mostra o impacto na fauna brasileira usando dados de satélites.

## Como Funciona?

1. **Pega dados** do INPE (queimadas detectadas por satélite)
2. **Cruza com dados** de espécies ameaçadas (IUCN Red List)
3. **Mostra em um mapa** onde estão as queimadas
4. **Calcula risco** para as espécies próximas
5. **Gera alertas** automáticos

## O Que Você Vê?

- 🗺️ Mapa interativo com queimadas
- 📊 Gráficos por bioma
- 🐾 Lista de espécies em risco
- 🚨 Nível de risco (baixo, médio, alto, crítico)
- 📥 Download dos dados

## Por Que Importa?

- **Proteção:** Identifica rapidamente onde as espécies ameaçadas estão em risco
- **Ação Rápida:** Órgãos ambientais podem agir em minutos, não em dias
- **Dados Públicos:** Qualquer pessoa pode acessar e entender o impacto
- **Decisões Melhores:** Governo e ONGs têm informações para agir

## Números

- 277.981 queimadas detectadas
- 90 espécies ameaçadas monitoradas
- 6 biomas cobertos
- Atualização em tempo real

## Tecnologia

- Python + Streamlit (interface)
- Folium (mapas)
- Plotly (gráficos)
- Dados do INPE + IUCN

## Impacto

Quando uma queimada é detectada perto de um habitat crítico, o sistema avisa imediatamente. Isso permite que órgãos de proteção ambiental intervenham rápido, salvando espécies ameaçadas de extinção.
